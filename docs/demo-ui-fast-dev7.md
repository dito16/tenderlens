# TenderLens FAST DEV 7: демонстрационный интерфейс

- SVG из предоставленного пользователем файла используется как локальный статический ресурс, без внешней загрузки.
- Убраны служебный баннер, маркетинговые пояснения, визуальные SHA/bbox и подробные внутренние предупреждения из пользовательской страницы.
- Ограничения импорта остались видимыми. Базовая оговорка о ручной проверке сохранена в подвале.
- Machine-readable evidence, SHA256, bbox, SQLite, API, экспорт и история не изменялись.
- UI-представление полей, единиц измерения, аванса и сравнения запусков локализовано.
- G4, gold/holdout, независимый M09 и публикация по-прежнему исключены.
- Сведения о лицензировании, отсутствии OCR и ограничениях достоверности доступны в README и release-gates, не скрываются от будущих пользователей.
